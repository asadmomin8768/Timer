# Timer

A simple and user-friendly **Timer web application** for setting and managing countdowns.

## ✨ Features

* Set countdown timer
* Start, pause, and reset timer
* Real-time countdown display
* Simple and responsive interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **HTML, CSS, and JavaScript** by building a functional timer application.
